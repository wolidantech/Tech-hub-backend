# DANQEL brand artwork

- `danqel-digital-institute.svg` is the full, transparent-background lockup for light surfaces, certificates, headers, and footers.
- `danqel-mark.svg` is the compact icon for avatars, small UI placements, and favicon derivatives.

The full lockup uses the institutional name **DANQEL DIGITAL INSTITUTE** and the exact tagline **Technology • Science • Digital Learning**. The dark wordmark is intended for light backgrounds; preserve the original proportions and do not stretch the artwork independently on each axis. Both files are accessible from the backend at `/brand/logo.svg` and `/brand/mark.svg`.
